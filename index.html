Discord Instructor Workspace

A Discord bot and web dashboard that let instructors run class sessions without typing raw commands. It records voice sessions, tracks attendance and participation, schedules sessions and announcements, and builds a report for each session.

The bot owns the Discord connection and every database write. The dashboard never talks to Discord itself: it calls the bot’s local API, and both sides read from one SQLite database.
